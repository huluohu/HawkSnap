## 1. 产品概述

**HawkSnap** 是一款免费、跨平台、轻量级的截屏与录屏工具。

- **Slogan**：像鹰一样准，一按就截。
- **定位**：免费纯本地工具——无账号、无云端、无遥测。
- **平台**：桌面三平台（Windows / macOS / Linux）+ Chrome/Edge 浏览器插件。
- **产品原则**（决策优先级从高到低）：
  1. **快而准**：热键到可框选 ≤150ms，智能吸附让选区一次到位。
  2. **轻量**：安装包 ≤15MB、常驻内存 ≤80MB。
  3. **本地与隐私**：一切处理本地完成，不联网上报。
  4. **跨平台一致**：同一套交互与快捷键，平台差异在文档中明示。

## 3. 功能需求

优先级：P0 = M1 必备；P1 = M2；P2 = M3/M4。

### 3.1 基础截图（P0）

- 三种模式：区域截图（默认，含智能吸附）、窗口截图、全屏截图（含多显示器分别捕获）。
- **冻结帧方案**：热键触发后立即捕获全部显示器当前帧，覆盖层显示冻结画面，用户在冻结帧上框选——所见即所得，无实时预览延迟，DPI 精确。
- 框选交互：鼠标拖拽；方向键 1px / Shift+方向键 10px 微调；边缘 8px 磁吸。
- 确认后动作浮条：复制到剪贴板（默认同时执行）、保存、贴图、标注、OCR、录 GIF、更多设置。
- 输出：PNG（默认，无损）/ JPEG（质量可调）；文件命名模板支持 `{app} {date} {time} {n}` 变量。
- 延时截图：1/2/3/5 秒可选，倒计时悬浮显示、可取消。

### 3.2 智能截图（P0）

- **窗口/UI 元素识别**：鼠标悬停自动高亮候选区域（窗口、控件、列表项等），单击即选中。
  - macOS：Accessibility（AXUIElement）；Windows：UI Automation；Linux X11：EWMH + XQueryTree；Linux Wayland：仅窗口级（门户协议限制，无元素吸附）。
- **贴图 Pin**：截图或剪贴板图像置顶桌面；滚轮缩放、Ctrl+滚轮调透明度、拖拽移动、双击进编辑器；支持同时多张贴图，贴图管理器统一管理。

### 3.3 标注编辑器 + OCR（P1）

- 编辑器：截图直接进入或从历史/贴图打开；画布 = 位图底 + 矢量标注层（导出时栅格化）。
- 工具集：选择/移动、矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克（像素化/模糊）、序号步骤气泡、裁剪；撤销/重做无步数限制（会话内）；颜色/粗细/字体样式记忆。
- **自研轻量矢量层**（Canvas API）：矩形/箭头/文字等 hit-test 复杂度可控，避免 300KB 级第三方依赖——契合轻量定位。
- **OCR**：RapidOCR（ONNX Runtime 本地推理，ch_PP-OCRv4 det+rec+cls，模型约 12MB 首次使用时按需下载）；识别结果以文本框浮层呈现，可单块复制、全部复制、导出 txt。
- 取色器（截图时按 C 拾色，复制 HEX/RGB）；像素标尺（选区边缘实时显示尺寸）。

### 3.4 录屏（P1 基础 / P2 进阶）

- 基础（随 M2 交付）：区域/窗口/全屏录制，30/60fps，MP4（H.264/HEVC 硬编码），光标可选录制 + 点击高亮涟漪；录制悬浮条：计时、暂停/恢复、停止；系统声与麦克风可各自开关并独立调节音量。
- 进阶（P2，随 M3 交付）：
  - GIF / APNG 导出（gifski 编码）；
  - 摄像头画中画（圆形/圆角矩形，位置大小录制中可调，硬编合成）；
  - 按键显示（keycast，可选）。

### 3.5 长截图（P2）

- 桌面端（M3）：滚动捕获 + 特征匹配拼接（ORB + 模板匹配，处理固定头部/侧边栏）；首发手动滚动模式（用户滚动，自动增量捕获），自动滚动模式视稳定性决定是否跟进。
- 浏览器插件（M4，MV3 + TypeScript）：整页截图（优先 `chrome.debugger` 的 `Page.captureScreenshot` 全页模式；降级为逐视口捕获 + 拼接）；懒加载图片自动触发加载；结果直接下载或经 Native Messaging 送入桌面端历史。

### 3.6 历史记录（P0 简版 / P1 完整）

- SQLite 存储：`shots(id, created_at, kind, path, thumb_path, w, h, app, title, ocr_text, tags, duration)`；OCR 文本入 FTS5 索引，支持按时间/类型/来源应用/文字内容搜索。
- 操作：重新编辑、重新贴图、打开所在目录、删除；保留策略（默认 500 条或 1GB，可调，超额自动清理最旧）。

### 3.7 设置 / i18n / 自动更新（P0，首版）

- 设置：热键（含冲突检测与候选建议）、输出格式与命名、保留策略、开机自启、外观（浅色/深色/跟随系统）、语言、更新开关。
- **i18n**：zh-CN / en-US，跟随系统默认、可手动覆盖；所有 UI 文案走 key（CI 校验覆盖率 100%，禁止硬编码）。
- **自动更新**：tauri-plugin-updater + GitHub Releases 通道；Ed25519 签名校验，校验失败拒绝安装并保留旧版；默认开启、可关闭；支持手动检查与更新日志展示。

## 7. 技术架构

### 7.1 技术栈

- **应用框架**：Tauri 2（多窗口：主面板、选区覆盖层、贴图窗口、编辑器、录制悬浮条）
- **前端**：React 18 + TypeScript + Vite + zustand（状态）+ Canvas API（编辑器矢量层）
- **核心**：Rust workspace `hawksnap-core`（平台抽象 + 业务逻辑），平台实现 `hawksnap-platform-{mac,windows,linux}`
- **插件**：Manifest V3 + TypeScript + Vite，与桌面端经 Native Messaging 通信

### 7.2 架构图

```
┌─ Web UI（React 18 + TS + Vite）
│    主面板 / 标注编辑器 / 历史与搜索 / 设置 / i18n(zh-CN, en-US)
├─ Tauri 2 IPC（commands + events）
│    透明置顶窗口：选区覆盖层(冻结帧) / 贴图 / 录制悬浮条
└─ hawksnap-core（Rust）
     ├─ capture   trait CaptureSource —— ScreenCaptureKit │ Graphics.Capture+DXGI │ X11+PipeWire
     ├─ detect    trait ElementDetector —— AXUIElement │ UIA │ EWMH+XQueryTree（Wayland 不实现）
     ├─ encode    trait Encoder —— VideoToolbox │ MediaFoundation │ VA-API（硬编）+ gifski(GIF)
     ├─ ocr       RapidOCR(ONNX Runtime)，模型按需下载校验 SHA256
     ├─ stitch    ORB 特征匹配 + 模板匹配拼接，固定区域检测
     ├─ hotkey    全局热键注册与冲突检测
     ├─ clipboard 跨平台剪贴板（图像/文本）
     ├─ history   SQLite(rusqlite) + FTS5
     └─ updater   tauri-plugin-updater 封装（签名验证/回退）

浏览器插件（MV3）── Native Messaging ──> 桌面端（写入 history / 唤起编辑器）
```

### 7.3 关键数据流

**截图**：`F1 → grab_screens(全显示器, 30–60ms) → 每显示器一个透明覆盖窗口(冻结帧) → detect.hover 高亮候选 → 框选/微调 → 确认 → 裁剪(DPI 换算) → 剪贴板 + 动作浮条 → history 入库(缩略图+元数据)`

**录屏**：`F6 → 选区(复用覆盖层) → CaptureSession.start(region, {fps, cursor, audio[]}) → 帧回调 → 硬编码 → MP4 分段写盘 → 暂停/恢复/停止 → 混音合成 → history`

**贴图生命周期**：`截图/剪贴板 → F2 → 置顶无边框窗口 → 缩放/透明度/拖拽 → 双击进编辑器或 Esc 关闭 → 贴图管理器`

### 7.4 关键决策记录（ADR 摘要）

1. **冻结帧覆盖层**（而非实时预览）：准确性优先，杜绝 WebView 渲染延迟；代价是覆盖层出现前有 30–60ms 捕获耗时，已含在 150ms 预算内。
2. **编辑器自研矢量层**（而非 Fabric.js）：省 ~300KB 依赖；标注工具的 hit-test 自研成本可控。
3. **OCR 用 RapidOCR**（而非系统原生）：三平台识别质量一致、中文强；代价是 12MB 模型按需下载。
4. **录屏编码走各平台原生硬编**（而非统一 ffmpeg）：包体与内存最优；代价是三条编码管线，由 `Encoder` trait 隔离。
5. **React（用户指定）**：接受比 Svelte 略大的运行时（~1–2MB 内存、几百 KB 包体），仍在 15MB/80MB 预算内。

## 9. 错误处理与边界

| 场景 | 处理 |
|---|---|
| macOS 权限缺失（屏幕录制/辅助功能） | 检测缺失 → 引导弹窗深链系统设置 → 返回后自动重试 |
| 热键被占用 | 列出占用应用，给出候选键，允许无热键启动（托盘菜单可用） |
| 多显示器 DPI/热插拔变化 | 监听显示配置变更，销毁并重建覆盖层与贴图坐标映射 |
| 磁盘空间不足 | 录屏启动前预检（估算码率×时长下限），不足则提示；历史按策略清理 |
| 硬编初始化失败 | 自动降级软编（x264）并提示性能影响 |
| Wayland 无捕获权限 | 引导完成 portal 授权；元素吸附功能置灰并说明 |
| OCR 模型下载失败 | 内置重试 + 手动下载入口 + SHA256 校验失败重下 |
| 更新失败/签名无效 | 保留旧版安装包，回退指引；更新检查失败静默降级为下次启动重试 |
| 插件找不到桌面端 | 引导安装桌面端；下载兜底不依赖桌面端 |

## 10. 测试策略

- **Rust**：`cargo test` 单元测试（core 纯逻辑）+ 平台桩（mock CaptureSource/Encoder）集成测试；覆盖率门槛 70%（capture/encode/stitch）。
- **前端**：Vitest + React Testing Library（编辑器工具逻辑、设置、历史搜索）；i18n key 覆盖 CI 检查。
- **E2E 冒烟**：Tauri WebDriver——热键截图→剪贴板断言、录屏 10s→文件存在且可解码。
- **性能基准**：脚本采集 §5/§6 指标 → CSV 入 CI 报告，超阈值 fail。
- **样本集回归**：OCR 500 张、拼接 20 场景、吸附 50 控件/平台，入仓库 `testdata/`。
- **手工矩阵**：§6.3 平台检查单，每里程碑发布前执行。
