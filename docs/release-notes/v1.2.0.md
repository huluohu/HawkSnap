# HawkSnap v1.2.0

## 新功能

- **截图动作浮条补全**：框选后的浮条现在有全部七个动作——复制、保存、标注、贴图、OCR、录 GIF、更多设置，全部可用（此前贴图 / OCR / GIF 是灰色占位）。
- **全屏截图一键入口**：托盘菜单新增「全屏截图」；多显示器逐屏分别保存入库，剪贴板取主显示器。
- **F3 长截图热键**：长截图有了自己的全局热键（可在设置中修改，默认 F3）。
- **录制 30/60 帧率可选**、**光标入镜可开关**：录制横幅上直接切换。
- **画布缩放**：编辑器支持 Ctrl/⌘+滚轮与工具栏按钮缩放（25%–400%），大图做细部标注、核对遮蔽覆盖不再费眼。
- **遮蔽块「模糊」模式**：马赛克工具新增像素化 / 模糊两种形态，随样式记忆。
- **画布内容 OCR**：编辑器里识别的是当前画面（裁剪后 + 已标注）——裁剪后不再错位，被马赛克遮住的文字不会被 OCR 结果暴露。
- **裁剪可撤销**：误裁不再丢标注——⌘Z 会连位图、标注、撤销历史一起恢复。
- **历史类型筛选**：主面板可按 截图 / 录屏 / 长截图 过滤；**历史上限可调**（50–10000 条，设置 → 历史记录）。
- **贴图管理**：主面板新增「贴图」卡片，可查看贴图列表并关闭单张。
- **托盘全双语**：托盘菜单、窗口标题随界面语言切换（此前托盘恒为中文）。
- **双语言错误提示**：录屏 / 长截图 / 贴图 / 编辑器等全部错误提示改为错误码 + 双语文案——英文界面下不再出现中文横幅。
- **浏览器插件整页降级**：调试通道不可用时，整页截图自动退回逐屏滚动拼接（固定表头可能随视口重复，界面有明示）。
- **文件名带真实应用名**：截图文件名与历史「来源应用」记录当前前台应用（如 Safari / Finder），不再是恒定的 HawkSnap。

## 修复

- 缩放屏（Retina 等非整数坐标）上点「标注」必定失败的错误。
- 录屏进行中截图选择区里按 F2 会贴出整屏冻结帧的问题；「最近截图」现在准确指向上一次确认的选区。
- 动作浮条在屏幕右缘被裁掉约 90px 的问题（改为按实际宽度定位）。
- 快速用户的拖拽会被覆盖层补发事件打断、选区凭空消失的问题。
- 冻结帧加载失败时无任何提示的问题（现在显示可读错误并可重试）。
- 倒计时浮窗不再抢走正在输入的应用焦点；底部显示「点击取消」提示。
- Windows/Linux 上权限页假绿「已授权」的问题——这两项权限门不存在，页面明示「无需授权」。
- 编辑器不再接受超过 8192px 的图片（巨幅长图此前会让画布失败或内存尖峰）；截图来源保存多次会重复入库的问题。
- 非按热键设置的重复绑定现在会被明确指出（此前报「可能被占用」，误导排查）。
- 热键注册失败提示给出候选键。
- 磁盘可用空间不足 1GB 时录屏启动前拒绝并提示（此前会写坏文件）。
- 应用启动 30 秒后自动检查更新（此前只碰托盘的用户永远不会触发检查）。

## 平台

- 功能矩阵与 v1.1.3 相同：截图 / 标注 / OCR / 历史 / 插件三平台一致；录屏、长截图、贴图、按键显示、窗口元素识别为 macOS 专属（其它平台入口明确报错）。Linux 捕获后端面向 X11，Wayland 暂不支持。

## 安装与更新

- dmg / NSIS / AppImage 支持应用内更新（设置 → 自动更新）；MSI 与 deb / rpm 通过安装新包升级。
- macOS 安装包为 adhoc 签名（无公证）；Windows 安装器未做代码签名（SmartScreen 会告警）。
