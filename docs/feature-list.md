# 功能清单对照：猎影 HawkSnap ↔ Snapzy

> 参考项目：[duongductrong/Snapzy](https://github.com/duongductrong/Snapzy)（Swift / SwiftUI，
> BSD-3-Clause，3.5k stars，CleanShot X 的开源替代）。
> 本文档梳理 Snapzy 的完整功能面，标出猎影的对应实现与缺口，作为后续迭代的排序依据。
>
> 口径：**已实现** = 代码在仓库里且有对应验收；**部分** = 主路径可用但覆盖不全；
> **缺** = 未实现；**不做** = 明确的产品决策不做（非能力缺失）。

---

## 一、Snapzy 功能全景（12 类）

### 1. 截图 Screenshot
- 全屏 / 区域捕获，**手动模式 / 应用窗口模式切换**（`A` 键切换，默认应用捕获）
- 已打开的第三方菜单栏弹窗（popover）在截图时不消失，且**保存时带透明圆角**
- 区域捕获后**内联标注**（先标注再存）
- 滚动截图 + **实时拼接预览**
- OCR 文字提取（Apple Vision 或自定义 OpenAI 兼容端点）+ 原生结果通知
- 透明物体抠图捕获（可选安全自动裁边）
- 窗口阴影捕获（macOS 14+）
- 多格式导出 PNG / JPG / WebP
- 隐藏桌面图标/挂件
- 录制中快速截图
- **取色器**：实时放大镜，点击复制任意像素 HEX → 再取 RGB / HSL / HSB / CMYK / OKLCH / SwiftUI

### 2. 屏幕录制 Screen Recording
- 视频或 GIF 输出；系统音频 + 麦克风
- 摄像头叠加（支持 iPhone 连续互通相机）
- 鼠标点击高亮、按键叠加、录制中实时屏幕标注
- 记住上次录制区域、GIF 尺寸调整、Follow Mouse 编辑的 Smart Camera 元数据

### 3. 标注编辑器 Annotation Editor
- 形状、箭头、文本、水印、实心矩形、模糊/像素化、**本地敏感信息自动打码**、计数器、
  带文字吸附的高亮（⌘ 旁路）、可调贝塞尔控制柄的曲线箭头、带边缘吸附的裁剪（⌘ 旁路）
  与一键内容自动裁剪（`A`）、去背景（配裁剪感知自动裁边）、3D 渲染的样机背景、
  缩放平移（捏合 + 键盘）、拖拽到其他应用（可选保留编辑态与编辑器再激活）、工具/动作快捷键可配

### 4. 捕获后动作 After Capture Settings
- **按模式的动作矩阵**（保存 / 快速访问 / 复制到剪贴板 / 标注）+ 全局去背景自动裁边开关（默认开）

### 5. 视频编辑器 Video Editor
- 可视化时间轴裁剪 + 帧条、Follow Mouse 自动聚焦缩放片段、壁纸背景 + 留白、
  自定义导出尺寸、GIF 动画预览器、撤销/重做

### 6. 快速访问 Quick Access
- 每次捕获后弹浮层面板：复制、编辑、拖到其他应用、两指滑动关闭、打开、删除；
  悬停卡片即可触发的可配快捷键

### 7. 捕获历史 Capture History
- 浮动历史面板 + 完整浏览器；类型/时间筛选、文件名搜索、快速复制/打开/删除、
  拖到其他应用复用（滚动安全的手势仲裁）、一键在标注/视频编辑器中重开、
  已提交截图的标注可恢复编辑、可配面板布局、保留策略

### 8. 快捷键 Shortcuts
- 截图/录制/标注工具的全局快捷键全可配、逐条开关、系统冲突检测

### 9. 引导 Onboarding
- 启动屏、首次运行语言选择、权限引导向导、快捷键配置

### 10. 本地化 Localization
- 英 / 越 / 简中 / 繁中 / 西 / 日 / 韩 / 俄 / 法 / 德 十语，macOS 原生「按 App 语言」支持

### 11. 云上传 Cloud Upload
- 自带存储（AWS S3 / Cloudflare R2），无第三方服务器；快速访问面板手动上传（截图/视频/GIF），
  标注内上传截图；凭据存 macOS 钥匙串（可加密码）、加密凭据导入导出、上传历史、
  可配置自动过期（1–90 天或永久）、生命周期规则、自定义域名

### 12. 高级 / 命令行 / 更新 / 平台
- **高级**：TOML 导出/导入、一次性配置目录授权、防抖后台同步、同步后再打开、启动时自动应用
  （`~/.config/snapzy/config.toml`，便携偏好 / dotfiles / 备份 / 跨机迁移）
- **命令行**：`snapzy` 命令，供 AI Agent 与脚本使用——无点击捕获显示器/窗口（含被遮挡窗口）/区域，
  返回 JSON 与退出码，按应用授权
- **更新与诊断**：Sparkle 应用内更新、问题报告（诊断日志包）、缓存管理
- **平台**：菜单栏应用、浅色/深色/跟随系统、Developer ID 签名 + 公证 + Hardened Runtime、
  用户自选目录用 security-scoped bookmark

## 三、缺口优先级（按「用户感知 × 实现成本」排序）

### P0 — 已在本次迭代落地
- **独立设置窗口**（侧栏分区 + 卡片式布局，Snapzy 式）：主面板收窄为「历史/快速访问」，
  设置独立成 900×620 的第二个窗口，8 个分区（通用/截屏/标注/历史/快捷键/权限/菜单栏/关于）
- **权限状态可视**：设置页「权限」分区实时显示屏幕录制 / 辅助功能授权态 + 一键跳系统设置
  （直击用户此前遇到的「明明授权了还弹横幅」痛点）

### P1 — 高感知、低成本
- **取色器增强**：覆盖层实时放大镜 + HEX 一键复制（编辑器已有基础取色器）
- **多格式导出 WebP**：Rust 侧 image 编码器已支持，成本低
- **动作后矩阵**：把固定动作浮条改成「按模式可配」（保存/复制/标注/快速访问的勾选矩阵）
- **历史类型/时间筛选**：SQLite 查询加 kind + 时间区间条件（schema 已有 kind 字段）

### P2 — 中等成本
- **快速访问浮层卡片**：每次捕获后弹可拖拽卡片（复制/编辑/拖到应用/滑动关闭）——
  Snapzy 的核心交互，猎影目前是动作浮条，功能重叠但体验形态不同
- **本地化扩语种**：繁中/日/韩（Snapzy 有 10 语）；Rust 侧文案 i18n 化
- **OCR 引擎可切换**：Apple Vision（系统原生、快）与本地 ONNX 双引擎

### P3 — 大成本
- **视频编辑器**（裁剪/缩放/背景/GIF 预览）：需要独立时间轴 UI 与渲染管线
- **配置导入导出**（TOML）：便携偏好 / dotfiles / 跨机迁移
- **录制中实时标注 + 鼠标点击高亮**
- **窗口阴影捕获 / 透明物体抠图**

### 不做（产品决策）
- 云上传（S3/R2）：猎影定位「纯本地、无账号、无云端」，与 Snapzy 的 BYO 云是两种取向
- 命令行 headless 捕获：与「桌面截图工具」定位不符（除非做脚本化刚需）
- iPhone 连续互通相机：依赖 Continuity 生态，优先级低

## 四、猎影的差异化优势（相对 Snapzy）

1. **三平台**：Windows / Linux 有真实安装包与更新通道（Snapzy 仅 macOS）
2. **浏览器插件**：Chrome/Edge 一键整页/选区截图 → 桌面端编辑（Snapzy 无）
3. **MIT 许可** + 公开仓库 + 源码包随 Release 分发（Snapzy 是 BSD-3，同样宽松）
4. **零遥测、零账号**：无本地/云端索引，无授权端点
5. **GIF 无质量税**：换用 MIT 的 `gif` crate（NeuQuant 量化），避免 AGPL 传染
